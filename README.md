# skills

A personal collection of [Agent Skills](https://skills.sh/) for AI coding agents.

## Install

Install all skills from this repo:

```bash
npx skills add glpalma/skills
```

Install a single skill:

```bash
npx skills add glpalma/skills --skill vertical-slice-plans
```

## Available skills

| Skill | Description |
| --- | --- |
| [`vertical-slice-plans`](vertical-slice-plans/SKILL.md) | Structure backend implementation plans so a human can implement them by hand, split into small vertical slices with a mermaid sequence diagram per request path. |

More skills will be added over time.
